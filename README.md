# AdvFab Conformance

The conformance suite evaluates an implementation as a black box against released API, security and provider contracts. A claim is tied to an exact implementation version and immutable digest; mutable tags are not valid identities.

Run `python3 verify_result.py examples/result.json`. Passing local tests does not grant CNCF status or imply endorsement by the project.
